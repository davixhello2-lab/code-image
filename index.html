Image Code

Crie pixel art e guarde em um arquivo .cimg

↓ Baixar Image Code Editor de pixel art (.exe para Windows) ↓ Baixar Image Code Leitor Abre arquivos .cimg (.exe para Windows)

Gratis. Nao precisa instalar Python.

O que é

  • O Image Code é um programa para criar e ver imagens feitas de números.
  • Cada pixel da imagem é um número de 0 a 23, e cada número é uma cor.
  • O desenho é salvo num arquivo de texto com a extensão .cimg.
  • O arquivo cabe em qualquer lugar, porque é só texto simples.
  • Qualquer pessoa pode abrir o .cimg no leitor e ver a imagem na hora.
  • O pacote tem dois programas: o editor, para desenhar, e o leitor, para abrir.

O editor

  • O Image Code (editor) é onde você desenha a sua pixel art.
  • Escolha o tamanho: 8x8, 16x16, 32x32, 64x64 ou 128x128.
  • Escolha uma das 24 cores da paleta e clique nos quadrados para pintar.
  • Arraste o mouse para pintar vários quadrados de uma vez.
  • Clique de novo num quadrado pintado com a mesma cor para ele voltar a ficar branco.
  • O balde preenche uma área inteira da mesma cor.
  • O conta-gotas pega a cor de um pixel, e o botão direito do mouse faz o mesmo.
  • Errou? Aperte Ctrl+Z para desfazer, até 50 passos.
  • A grade pode ser ligada e desligada, para ver o desenho sem as linhas.
  • Salve como .cimg ou exporte um PNG no tamanho real da imagem.

O leitor

  • O Image Code Leitor abre somente arquivos .cimg.
  • Ele mostra a imagem ampliada numa janela, sem precisar do editor.
  • Ao abrir, ele também salva um PNG ao lado do arquivo.
  • Você pode arrastar um .cimg em cima do programa para abrir rápido.
  • Se faltarem números no arquivo, o leitor completa com preto.
  • Se aparecer um número fora da paleta, ele mostra um aviso de erro.

O formato do arquivo

  • O formato é uma linha só, assim: Img: 4x4(2 2 4 4 ...).
  • Primeiro vem a largura e a altura, e depois os números dentro dos parênteses.
  • Os números são lidos da esquerda para a direita, de cima para baixo.
  • Uma imagem 64x64 tem 4096 números, um para cada pixel.
  • Por ser texto, o .cimg pode ser aberto no Bloco de Notas.
  • Dá para pedir a uma IA para escrever a sintaxe e colar num arquivo .cimg.
  • Você também pode escrever o desenho na mão, número por número.
  • O 0 é preto e o 1 é branco, e as outras cores seguem a paleta abaixo.

Como usar

  • Baixe os dois programas nos botões desta página.
  • Os arquivos são .exe e funcionam no Windows.
  • Não precisa instalar Python nem nenhum outro programa.
  • Coloque os dois numa pasta de sua escolha, por exemplo na área de trabalho.
  • Dê dois cliques no Image Code para abrir o editor.
  • Para abrir um .cimg com dois cliques, clique nele com o botão direito.
  • Escolha “Abrir com” e aponte para o Image Code Leitor.
  • Marque a opção de sempre abrir com esse programa.
  • A partir daí, todo .cimg abre direto no leitor.
  • Para remover, é só apagar os dois arquivos.

Avisos

  • O Windows pode mostrar a tela azul “O Windows protegeu o computador”.
  • Isso acontece com programas novos que ainda não são conhecidos.
  • Clique em “Mais informações” e depois em “Executar assim mesmo”.
  • O antivírus também pode reclamar, e isso costuma ser alarme falso.
  • Baixe os programas somente desta página, para ter certeza de que são os originais.
  • O primeiro início pode demorar alguns segundos.

Dicas

  • Comece com 16x16, que é rápido de desenhar e fica bonito.
  • Use o tamanho 64x64 quando quiser mais detalhes.
  • Compartilhe seus .cimg com os amigos, eles abrem no leitor.
  • Divirta-se e mostre o que você criou!
